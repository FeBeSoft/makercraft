# MakerCraft v0.1.1 bêta 20261128 - version test

Deuxième version test de MakerCraft, pour Windows 10 / 11 (64 bits). C'est toujours une **préversion** : elle sert à recueillir vos avis. Essayez-la d'abord **avec l'émulateur intégré**, sans machine réelle, et ne l'utilisez pas encore pour un travail qui compte.

*Second test release, for Windows 10/11 (64-bit), still a **pre-release** for feedback. The interface is in French for now. English summary at the end.*

Cette version est centrée sur **le dessin** (étape Dessin de l'atelier Fraisage 2,5D), pour se rapprocher de Carbide Create et de Galaad.

## Contenu du zip

- `makercraft.exe` : l'application (ateliers CNC et Machines)
- `makercraft-outils.exe` : la bibliothèque d'outils, autonome
- `exemple-porte-cles.mkc` : un projet d'exemple
- `LISEZMOI.txt` et `LICENSE` (GPL-3.0)

Décompressez le zip où vous voulez et lancez `makercraft.exe`. L'exécutable n'est pas signé : si Windows SmartScreen affiche un avertissement, cliquez sur « Informations complémentaires », puis « Exécuter quand même ».

## Nouveautés du dessin

- **Ruban** à groupes : la flèche à droite du titre d'un groupe déplie ses autres fonctions ; **clic droit** sur une icône à variantes (petit coin en bas à droite) : cercle par 2 ou 3 points, tangentes, 11 sortes d'arcs, ellipse, réseau circulaire, points, miroir ou retournement, construction, cotes, contraintes. La dernière variante utilisée reste affichée.
- **Sélection façon Carbide Create** : clic (Maj pour ajouter), rectangle glissé, cadre à poignées pour déplacer, mettre à l'échelle (proportions liées ou non) et tourner ; **Entrée** ouvre les cotes, comme dans Galaad.
- **Colonne de droite** : Propriétés (position, taille, rayon, rotation, point de référence), 3D, Commentaires par contour ; historique de construction.
- **Arbre des contours** : œil, cadenas, renommer, supprimer, envoyer des objets dans un autre contour, couleurs jamais répétées.
- **Réseaux** rectangulaires et circulaires **qui restent liés** à leur forme d'origine : nombre, pas, angle modifiables après coup, y compris après enregistrement.
- **Nouvelles formes et commandes** : étoile, oblong, points de perçage, retourner, caler, étirer, remplir le brut, édition des nœuds (double-clic), polyligne, diviser, jalonner, allonger, inverser le sens, raccord lisse, doublons, réparer, **dégagements dogbone et T-bone**.
- **Aides au tracé** : accroches réglables (F3), grille magnétique (F9), ortho (F8), polaire (F10), accroches sur le brut, calculs dans les valeurs (`W/2+5`), longueur et angle près du curseur, lignes de construction et cotes jamais usinées, mesure de distance et d'aire.
- **Menus** : clic droit (commande en cours, sélection, sommet), clic molette (vues) ; Ctrl+Z / Ctrl+Y.
- **Invites de CadCraft en français.**

## Autres changements

- Barre de titre : nom du fichier et version ; état de la machine sur l'onglet Machine et dans la barre d'état.
- **Enregistrer les modifications ?** avant de fermer ou d'ouvrir un autre projet.
- **Mettre à jour** : vérifie sur GitHub s'il existe une nouvelle version, au clic, ou au démarrage si vous cochez l'option (non cochée par défaut). Seule l'adresse IP de l'ordinateur est transmise à GitHub.
- Options : commandes de CadCraft dans la ligne de commande, origine affichée en 2D et en 3D, menu « Extensions » (caché par défaut).
- Amont : SolidCraft v0.51.2 ; CadCraft reste en v0.20.1.

## English summary

Second test release for Windows 10/11 (64-bit), interface in French. Focus on the drawing step: grouped ribbon with right-click variants, Carbide-style selection frame (move, scale, rotate), Galaad-style dimension box, Properties / 3D / Comments panel, contour tree (visibility, lock, rename, delete, unique colours), associative rectangular and polar arrays editable after the fact, new shapes and commands (star, slot, drill points, flip, align, stretch, fit to stock, node editing, dogbone and T-bone reliefs...), drawing aids (object snaps, grid, ortho, polar, stock snaps, expressions, construction lines and dimensions), context menus and undo shortcuts, French CadCraft prompts. Also: save prompt before closing, on-demand update check from GitHub (optional check at startup, off by default), SolidCraft v0.51.2.
