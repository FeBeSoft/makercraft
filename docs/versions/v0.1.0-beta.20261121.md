# MakerCraft v0.1.0 bêta 20261121 - version test

Première version test publique de MakerCraft, pour Windows 10 / 11 (64 bits). C'est une **préversion** : elle sert à recueillir vos avis. Essayez-la d'abord **avec l'émulateur intégré**, sans machine réelle, et ne l'utilisez pas encore pour un travail qui compte.

*First public test release, for Windows 10/11 (64-bit). This is a **pre-release** for feedback: try it first with the built-in emulator, and do not rely on it for real work yet. The interface is in French for now. English summary at the end.*

## Contenu du zip

- `makercraft.exe` : l'application (ateliers CNC et Machines)
- `makercraft-outils.exe` : la bibliothèque d'outils, autonome
- `exemple-porte-cles.mkc` : un projet d'exemple (porte-clés en OSB 9 mm : gravure, poche, perçage, découpe)
- `LISEZMOI.txt` et `LICENSE` (GPL-3.0)

Décompressez le zip où vous voulez et lancez `makercraft.exe`. L'exécutable n'est pas encore signé : si Windows SmartScreen affiche un avertissement, cliquez sur « Informations complémentaires », puis « Exécuter quand même ». Pour une 3018 en USB, installez le pilote CH340 si Windows ne reconnaît pas le port. MakerCraft ne fait **aucune connexion réseau**.

## Ce qui fonctionne

**Atelier CNC - Fraisage 2,5D**, en six étapes :
- Machine (Genmitsu 3018-PRO pour l'instant), Brut (dimensions, matière, zéro pièce, zones de bridage) ;
- Dessin avec le moteur de CadCraft, import DXF / DWG, un calque = un contour ;
- Parcours : contour extérieur ou intérieur, sur le trait, poche, perçage, gravure, avec les vitesses proposées par la banque d'outils ;
- Simulation : brides, profondeur, durée ;
- Usinage : G-code Grbl avec le rappel de l'outil et de la pince ER11 à chaque changement d'outil, envoi vers l'atelier Machines ;
- projets `.mkc`.

**Atelier Machines** :
- Fiche de la machine et des équipements installés ;
- Pilotage : positions pièce et table, zéro par axe, déplacement manuel (souris ou clavier), broche, arrêt logiciel, vue 3D / 2D, envoi d'un programme, console ;
- Grbl 1.1 / grblHAL par USB, ou émulateur intégré (choisi par défaut) ;
- alarmes et erreurs Grbl expliquées en français ;
- sans zéro valable, les déplacements longs sur une vraie machine demandent une ou deux validations.

**Bibliothèque d'outils** : profil de la 3018-PRO, 11 outils d'atelier avec leur pince, valeurs de coupe pour l'OSB, le MDF, le contreplaqué, la mousse et l'acrylique.

## En cours et prévu

- En cours : calibrage avec assistants, réglages Grbl, entretien et journal, caméra, palpage ; simulation de l'enlèvement de matière, ponts d'attache, V-carve, rampes.
- v0.2 : la 3018-PRO pleinement utilisable, avec au moins les fonctions de Carbide Create. v0.3 : Isel CPM 2018.
- Ensuite : usinage 3D, gravure d'images, laser, PCB. L'import des dessins Galaad est envisagé.

## Un logiciel, deux usages

Le mode se choisit dans **Options > Général** :
- **Maker** : tout est accessible.
- **En classe (prof / élève)** : en mode élève, la fiche machine est en lecture seule, les réglages sont masqués, les pas et la vitesse sont limités, la broche, le déverrouillage, la console et le lancement d'un programme sont réservés au prof.

Prévu : échange des projets avec les élèves par le **Nuage apps.education du prof** (dépôt par lien, sans compte, puis file d'attente des usinages dans MakerCraft), mot de passe prof, option « maker seulement », validation du prof avant usinage, modèles de projets.

> **Aperçu** : le mode élève n'est pas encore protégé par un mot de passe et ne remplace jamais la surveillance de l'enseignant.

À essayer en priorité :
1. l'installation et le premier lancement ;
2. ouvrir l'exemple, ou importer un DXF, créer des parcours et écrire le G-code ;
3. se connecter à l'émulateur et jouer le programme ;
4. avec une machine Grbl : seulement **lire** son état au début, sans usiner, et la décrire dans [Machines](https://github.com/FeBeSoft/makercraft/discussions/categories/machines) (modèle, courses, broche, pinces) ;
5. vos outils et leurs conditions de coupe dans [Outils](https://github.com/FeBeSoft/makercraft/discussions/categories/outils) ;
6. enseignants : votre avis sur le mode élève et sur l'échange par le Nuage, dans [En classe](https://github.com/FeBeSoft/makercraft/discussions/categories/en-classe) ;
7. ce qui est clair, ce qui ne l'est pas, ce qui manque par rapport à Carbide Create ou à vos logiciels habituels.

## English summary

Test release for Windows 10/11 (64-bit), interface in French. Included: the CNC 2.5D milling workshop (CadCraft drawing engine, DXF/DWG import, outside/inside profile, on-line, pocket, drilling and engraving toolpaths, checks, Grbl G-code), the Machines workshop (machine sheet, jog, spindle, software stop, program sending, built-in emulator, Grbl alarms explained) and the standalone tool library. A classroom mode (teacher / pupil) is included as a preview, without password yet. Please try it with the emulator first and send feedback: questions in [Q&A](https://github.com/FeBeSoft/makercraft/discussions/categories/q-a), your machine in [Machine Profiles](https://github.com/FeBeSoft/makercraft/discussions/categories/machine-profiles), your cutting tools in [Tools](https://github.com/FeBeSoft/makercraft/discussions/categories/tools), bugs in the [issues](https://github.com/FeBeSoft/makercraft/issues/new/choose), or makercraft@fe-be.fr.
