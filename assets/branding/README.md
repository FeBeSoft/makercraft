# Identité visuelle MakerCraft

| Fichier | Usage |
|---|---|
| `makercraft.ico` | icône Windows (16 à 256 px), intégrée aux exécutables par `build.rs` |
| `makercraft-256.png`, `makercraft-512.png` | icône pour l'interface (fenêtre, À propos) et le web |
| `makercraft-about.jpg` | illustration de la page « À propos » (1264 × 848) |

Les originaux haute définition (PNG 1024, `.icns` macOS, essais) restent dans `_icon/`, atelier
de travail non suivi par git. Régénérer les tailles depuis `_icon/MakerCraft.png` si l'icône change.

Origine : visuels générés par IA (Google Gemini) à partir de prompts de Manu Firre, retouchés
(luminosité, tailles). Ce sont des créations originales du projet ; pas de logo ni de marque tiers.
Ne pas les confondre avec les marques ArtCraft (projet indépendant, non affilié).
